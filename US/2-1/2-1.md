# Story 2.1: Seller Dashboard

Status: ready-for-dev

## Story

As a seller,
I want to view my product dashboard,
so that I can see all my listings and their status at a glance.

## Acceptance Criteria

1. **Given** a logged-in seller navigates to their dashboard **When** the page loads **Then** they see a list of all their products with name, photo thumbnail, price, stock, and status (active/inactive)

2. **Given** a seller has no products yet **When** they view their dashboard **Then** they see an empty state with a clear call-to-action to add their first product

## Tasks / Subtasks

- [ ] Task 1: Backend — Seller products endpoint (AC: #1, #2)
  - [ ] Create SellerProductController@index (GET /api/seller/products)
  - [ ] Return only products belonging to the authenticated seller
  - [ ] Create ProductResource for API response (name, photo, price, stock, status)
  - [ ] Apply auth:api + role:vendeur middleware
- [ ] Task 2: Frontend — Dashboard page (AC: #1, #2)
  - [ ] Create SellerDashboardPage.vue
  - [ ] Add route /seller/dashboard (protected, role: vendeur)
  - [ ] Display product list as table/cards (photo thumbnail, name, price, stock, status badge)
  - [ ] Empty state with CTA "Ajouter mon premier produit" linking to creation form
- [ ] Task 3: Frontend — Product store (AC: #1)
  - [ ] Create useSellerProductStore with fetchProducts action
  - [ ] Handle loading/error states
- [ ] Task 4: Tests (AC: #1, #2)
  - [ ] Pest: test seller sees only their products, empty state
  - [ ] Vitest: test SellerDashboardPage component
