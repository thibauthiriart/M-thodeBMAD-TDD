# Story 1.2: User Login & Logout

Status: ready-for-dev

## Story

As a registered user,
I want to log in and log out,
so that I can securely access my account.

## Acceptance Criteria

1. **Given** a registered user is on the login page **When** they enter valid email and password **Then** they receive an auth token and are redirected to the homepage **And** the token has an expiration period

2. **Given** a user enters incorrect credentials **When** the form is submitted **Then** an error message indicates invalid credentials without revealing which field is wrong

3. **Given** a logged-in user clicks logout **When** the action is confirmed **Then** the token is invalidated and the user is redirected to the homepage

## Tasks / Subtasks

- [ ] Task 1: Backend — Login endpoint (AC: #1, #2)
  - [ ] Create LoginRequest Form Request (email required, password required)
  - [ ] Create AuthController@login endpoint (POST /api/login)
  - [ ] Validate credentials, issue Passport token with expiration
  - [ ] Return generic error on invalid credentials (no field reveal)
- [ ] Task 2: Backend — Logout endpoint (AC: #3)
  - [ ] Create AuthController@logout endpoint (POST /api/logout)
  - [ ] Revoke current user token
- [ ] Task 3: Frontend — Login page (AC: #1, #2)
  - [ ] Create LoginPage.vue with form (email, password)
  - [ ] Add route /login in Vue Router
  - [ ] Call API, store token, redirect to homepage
  - [ ] Display error message on invalid credentials
- [ ] Task 4: Frontend — Logout (AC: #3)
  - [ ] Add logout action in useAuthStore
  - [ ] Call API, clear token/user, redirect to homepage
  - [ ] Add logout button in navigation header
- [ ] Task 5: Tests (AC: #1, #2, #3)
  - [ ] Pest: test login success, invalid credentials, logout
  - [ ] Vitest: test LoginPage component

## Dev Notes

- Auth via Laravel Passport v13 (personal access tokens)
- NFR8: tokens expirent apres une periode d'inactivite
- Message d'erreur generique sur login fail (securite)
- Pas de "remember me" pour le MVP
