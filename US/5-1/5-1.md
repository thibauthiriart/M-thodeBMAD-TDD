# Story 5.1: Similar Product Recommendations

Status: ready-for-dev

## Story

As a visitor or buyer,
I want to see similar product recommendations on each detail page,
so that I can discover alternatives or complementary components.

## Acceptance Criteria

1. **Given** a user is on a product detail page **When** the page loads **Then** a "Similar products" section displays up to 6 products from the same category and a close price range

2. **Given** similar products are displayed **When** the user clicks on a recommendation **Then** they are navigated to that product's detail page

3. **Given** no similar products exist (category empty or only this product) **When** the detail page loads **Then** the recommendations section is hidden gracefully

## Tasks / Subtasks

- [ ] Task 1: Backend — Recommendations endpoint (AC: #1, #3)
  - [ ] Create RecommendationController@similar (GET /api/products/{id}/recommendations)
  - [ ] Query: same category, price within +/- 30% of current product, exclude current product
  - [ ] Limit to 6 results, order by price proximity
  - [ ] Return empty array if no matches (frontend handles gracefully)
  - [ ] Only return active products
- [ ] Task 2: Frontend — Recommendations section (AC: #1, #2, #3)
  - [ ] Create RecommendationSection.vue component
  - [ ] Display on ProductDetailPage below main content
  - [ ] Show up to 6 product cards (photo + name + price)
  - [ ] Click navigates to product detail page
  - [ ] If empty: hide section entirely (no "No recommendations" message)
- [ ] Task 3: Tests (AC: #1, #2, #3)
  - [ ] Pest: test recommendations return same category, price range, max 6, excludes self, empty case
  - [ ] Vitest: test RecommendationSection component

## Dev Notes
