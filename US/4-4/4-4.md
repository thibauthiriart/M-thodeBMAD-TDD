# Story 4.4: Order Checkout

Status: ready-for-dev

## Story

As a buyer,
I want to validate my order,
so that I can complete my purchase.

## Acceptance Criteria

1. **Given** a buyer has products in their cart **When** they click "Validate order" **Then** an order is created with all cart items, quantities and total price **And** the cart is emptied **And** a confirmation page shows the order summary

2. **Given** a buyer validates an order **When** the order is created **Then** the order is durably stored and cannot be lost **And** the stock of each purchased product is decremented

3. **Given** a buyer tries to validate an order with an empty cart **When** the checkout action is triggered **Then** an error message indicates the cart is empty

- Gestion des race conditions sur le stock (lock ou retry)
- Logique metier dans OrderService, PAS dans le controller
