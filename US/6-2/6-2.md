# Story 6.2: Listing Moderation

Status: ready-for-dev

## Story

As an admin,
I want to view all product listings and activate or deactivate them,
so that I can remove inappropriate or fraudulent listings.

## Acceptance Criteria

1. **Given** an admin navigates to the listing moderation page **When** the page loads **Then** they see a list of all products with: name, seller, price, category, status (active/inactive)

2. **Given** an admin clicks "Deactivate" on an active listing **When** the action is confirmed **Then** the listing is hidden from the public catalogue immediately

3. **Given** an admin clicks "Activate" on an inactive listing **When** the action is confirmed **Then** the listing becomes visible in the public catalogue again

## Tasks / Subtasks

- [ ] Task 1: Backend — Admin product list endpoint (AC: #1)
  - [ ] Create AdminProductController@index (GET /api/admin/products)
  - [ ] Return paginated list: name, seller name, price, category, is_active
  - [ ] Apply auth:api + role:admin middleware
  - [ ] Include ALL products (active and inactive)
  - [ ] Create AdminProductResource
- [ ] Task 2: Backend — Admin toggle product status (AC: #2, #3)
  - [ ] Create AdminProductController@toggleStatus (PATCH /api/admin/products/{id}/toggle-status)
  - [ ] Toggle is_active boolean (admin can override seller status)
  - [ ] Return updated resource
- [ ] Task 3: Frontend — Listing moderation page (AC: #1, #2, #3)
  - [ ] Create AdminProductsPage.vue
  - [ ] Add route /admin/products (protected, role: admin)
  - [ ] Display product table: name, seller, price, category, status badge
  - [ ] Activate/Deactivate toggle per product
  - [ ] Filterable by status (all/active/inactive)
- [ ] Task 4: Tests (AC: #1, #2, #3)
  - [ ] Pest: test list all products (admin), toggle product status
  - [ ] Vitest: test AdminProductsPage component

## Dev Notes

- Admin peut desactiver n'importe quelle annonce (override vendeur)
- Admin peut reactiver une annonce desactivee par le vendeur
- Pas de notification au vendeur pour le MVP
- Table differente du catalogue public (montre tout, pas de filtre actif par defaut)
