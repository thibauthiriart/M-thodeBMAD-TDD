# Story 6.3: Platform Analytics Dashboard

Status: ready-for-dev

## Story

As an admin,
I want to view basic platform analytics,
so that I can monitor the health and growth of the marketplace.

## Acceptance Criteria

1. **Given** an admin navigates to the analytics dashboard **When** the page loads **Then** they see: total number of products (active/inactive), total number of users (by role), total number of orders

2. **Given** the analytics data changes (new user, new product, new order) **When** the admin refreshes the page **Then** the counters reflect the current state

## Tasks / Subtasks

- [ ] Task 1: Backend — Analytics endpoint (AC: #1, #2)
  - [ ] Create AdminAnalyticsController@index (GET /api/admin/analytics)
  - [ ] Return counts:
    - products_total, products_active, products_inactive
    - users_total, users_buyers, users_sellers
    - orders_total
  - [ ] Apply auth:api + role:admin middleware
  - [ ] Cache with Redis (TTL 60s) for performance
- [ ] Task 2: Frontend — Analytics dashboard (AC: #1, #2)
  - [ ] Create AdminDashboardPage.vue
  - [ ] Add route /admin (protected, role: admin)
  - [ ] Display counters as cards/widgets:
    - Produits: total / actifs / inactifs
    - Utilisateurs: total / acheteurs / vendeurs
    - Commandes: total
  - [ ] Refresh on page load (data is fresh on each visit)
- [ ] Task 3: Tests (AC: #1, #2)
  - [ ] Pest: test analytics endpoint returns correct counts, admin-only access
  - [ ] Vitest: test AdminDashboardPage component

## Dev Notes

- FR28: analytics basiques (compteurs)
- Compteurs simples avec COUNT queries
- Cache Redis 60s pour eviter des queries repetees
- Pas de graphiques/charts pour le MVP (juste des compteurs)
- Pas de real-time sur les analytics (refresh page = fresh data)
