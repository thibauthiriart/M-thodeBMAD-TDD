# Story 2.4: Activate/Deactivate Product

Status: ready-for-dev

## Story

As a seller,
I want to activate or deactivate one of my products,
so that I can temporarily hide a product without deleting it.

## Acceptance Criteria

1. **Given** a seller views an active product in their dashboard **When** they click "Deactivate" **Then** the product status changes to inactive and it is no longer visible in the public catalogue

2. **Given** a seller views an inactive product in their dashboard **When** they click "Activate" **Then** the product status changes to active and it becomes visible in the public catalogue

## Tasks / Subtasks

- [ ] Task 1: Backend — Toggle status endpoint (AC: #1, #2)
  - [ ] Create SellerProductController@toggleStatus (PATCH /api/seller/products/{id}/toggle-status)
  - [ ] Toggle is_active boolean
  - [ ] Scope to authenticated seller's products
  - [ ] Return updated ProductResource
- [ ] Task 2: Frontend — Toggle button (AC: #1, #2)
  - [ ] Add activate/deactivate button on each product card in SellerDashboardPage
  - [ ] Call API, update product in store optimistically
  - [ ] Visual feedback: status badge updates immediately
- [ ] Task 3: Tests (AC: #1, #2)
  - [ ] Pest: test toggle active→inactive, inactive→active, ownership check
  - [ ] Vitest: test toggle button behavior

## Dev Notes

- Toggle simple (flip is_active)
- Le catalogue public ne montre que les produits avec is_active = true
- Pas de confirmation dialog pour le toggle (action reversible)
