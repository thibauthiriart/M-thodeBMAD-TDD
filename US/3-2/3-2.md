# Story 3.2: Product Grid (Master View)

Status: ready-for-dev

## Story

As a visitor or buyer,
I want to see a grid of products with photo and intuitive name,
so that I can visually scan and identify components quickly.

## Acceptance Criteria

1. **Given** a user is on a category page **When** products are displayed **Then** each product card shows a photo and an intuitive name **And** products from multiple sellers are displayed together

2. **Given** there are more products than fit on one page **When** the user scrolls or navigates **Then** products are paginated or lazy-loaded for performance

3. **Given** a user clicks on a product card **When** the click is registered **Then** they are navigated to the product detail page

## Tasks / Subtasks

- [ ] Task 1: Backend — Product list endpoint (AC: #1, #2)
  - [ ] Ensure CatalogController returns paginated products with photo_url and name
  - [ ] Only return active products (is_active = true)
  - [ ] Include seller info (name) in response
  - [ ] FR30: products from multiple sellers mixed together
- [ ] Task 2: Frontend — Product grid component (AC: #1, #2, #3)
  - [ ] Create ProductGrid.vue component (reusable)
  - [ ] Each card: product photo + name + price
  - [ ] Click navigates to /products/{id}
  - [ ] Responsive grid: 4 cols desktop, 2 cols tablet, 1 col mobile
- [ ] Task 3: Frontend — Pagination (AC: #2)
  - [ ] Implement pagination or infinite scroll
  - [ ] Lazy-load images for performance
- [ ] Task 4: Tests (AC: #1, #2, #3)
  - [ ] Pest: test product list returns only active products, multi-seller
  - [ ] Vitest: test ProductGrid component
