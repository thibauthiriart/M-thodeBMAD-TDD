# Story 6.1: User Account Management

Status: ready-for-dev

## Story

As an admin,
I want to view all user accounts and activate or deactivate them,
so that I can manage platform access and handle problematic users.

## Acceptance Criteria

1. **Given** an admin navigates to the user management page **When** the page loads **Then** they see a list of all users with: name, email, role, status (active/inactive), registration date

2. **Given** an admin clicks "Deactivate" on an active user account **When** the action is confirmed **Then** the account is deactivated, the user can no longer log in, and if the user is a seller all their products become invisible in the catalogue

3. **Given** an admin clicks "Activate" on an inactive user account **When** the action is confirmed **Then** the account is reactivated and the user can log in again

## Tasks / Subtasks

- [ ] Task 1: Backend — Admin user list endpoint (AC: #1)
  - [ ] Create AdminUserController@index (GET /api/admin/users)
  - [ ] Return paginated list: name, email, role, is_active, created_at
  - [ ] Apply auth:api + role:admin middleware
  - [ ] Create AdminUserResource
- [ ] Task 2: Backend — Toggle user status endpoint (AC: #2, #3)
  - [ ] Create AdminUserController@toggleStatus (PATCH /api/admin/users/{id}/toggle-status)
  - [ ] Toggle is_active boolean on user
  - [ ] If deactivating a seller: set all their products is_active = false
  - [ ] If reactivating a seller: do NOT auto-reactivate products (seller decides)
  - [ ] Revoke active tokens on deactivation
- [ ] Task 3: Backend — User is_active migration (AC: #2, #3)
  - [ ] Add is_active (boolean, default true) to users table if not exists
  - [ ] Add check in login endpoint: reject login if is_active = false
- [ ] Task 4: Frontend — User management page (AC: #1, #2, #3)
  - [ ] Create AdminUsersPage.vue
  - [ ] Add route /admin/users (protected, role: admin)
  - [ ] Display user table with columns: name, email, role, status badge, date
  - [ ] Activate/Deactivate toggle button per user
  - [ ] Confirmation before deactivation (seller products will be hidden)
- [ ] Task 5: Tests (AC: #1, #2, #3)
  - [ ] Pest: test list users, toggle status, seller products hidden on deactivate
  - [ ] Pest: test deactivated user cannot login
  - [ ] Vitest: test AdminUsersPage component

## Dev Notes

- Tokens revoques a la desactivation (securite)
- Login check: is_active = true requis
