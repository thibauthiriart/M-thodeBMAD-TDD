docn # Story 1.1: User Registration with Role Selection

Status: ready-for-dev

## Story

As a visitor,
I want to create an account by choosing my role (buyer or seller),
so that I can access features specific to my profile.

## Acceptance Criteria

1. **Given** a visitor is on the registration page **When** they fill in email, password, password confirmation and select a role (acheteur or vendeur) **Then** an account is created with the selected role **And** the password is hashed with bcrypt **And** the user is automatically logged in and redirected to the homepage

2. **Given** a visitor submits a registration form with an already used email **When** the form is submitted **Then** an error message indicates the email is already taken

3. **Given** a visitor submits a registration form with an invalid password (< 8 characters) **When** the form is submitted **Then** an error message indicates password requirements

## Tasks / Subtasks

- [ ] Task 1: Backend — Registration endpoint (AC: #1, #2, #3)
  - [ ] Create RegisterRequest Form Request with validation (email unique, password min 8 chars, role in [acheteur, vendeur])
  - [ ] Create AuthController@register endpoint (POST /api/register)
  - [ ] Hash password with bcrypt, create user, return Passport token
  - [ ] Return appropriate error responses for validation failures
- [ ] Task 2: Backend — User model & migration (AC: #1)
  - [ ] Create/update User migration (email, password, name, role enum)
  - [ ] Add role field to User model with enum cast
- [ ] Task 3: Frontend — Registration page (AC: #1, #2, #3)
  - [ ] Create RegisterPage.vue with form (email, password, confirm, role selector)
  - [ ] Add route /register in Vue Router
  - [ ] Implement form validation (client-side)
  - [ ] Call API, store token in auth store, redirect to homepage
  - [ ] Display server-side validation errors
- [ ] Task 4: Frontend — Auth store (AC: #1)
  - [ ] Create/update useAuthStore with register action
  - [ ] Store token, user data, handle loading/error states
- [ ] Task 5: Tests (AC: #1, #2, #3)
  - [ ] Pest: test registration success, duplicate email, invalid password
  - [ ] Vitest: test RegisterPage component
