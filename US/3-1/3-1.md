# Story 3.1: Category Navigation

Status: ready-for-dev

## Story

As a visitor or buyer,
I want to browse components organized by category,
so that I can quickly find the type of component I need.

## Acceptance Criteria

1. **Given** a user arrives on the homepage **When** the page loads **Then** they see all 8 categories displayed clearly: CPU, GPU, RAM, Stockage, CM, Alimentation, Boitier, Peripheriques

2. **Given** a user clicks on a category **When** the category page loads **Then** only products from that category are displayed **And** the page loads in under 2 seconds

3. **Given** a visitor is not logged in **When** they browse categories and product listings **Then** they can access all catalogue pages without restriction

## Tasks / Subtasks

- [ ] Task 1: Backend — Categories & products by category (AC: #1, #2)
  - [ ] Create CatalogController@categories (GET /api/categories) — returns the 8 fixed categories
  - [ ] Create CatalogController@productsByCategory (GET /api/categories/{slug}/products) — returns paginated active products
  - [ ] No auth required (public routes)
- [ ] Task 2: Frontend — Homepage with categories (AC: #1, #3)
  - [ ] Create HomePage.vue with category grid
  - [ ] Each category card: icon/image + name
  - [ ] Click navigates to /categories/{slug}
- [ ] Task 3: Frontend — Category page (AC: #2, #3)
  - [ ] Create CategoryPage.vue
  - [ ] Add route /categories/{slug}
  - [ ] Fetch and display products for selected category
  - [ ] No auth guard (public)
- [ ] Task 4: Tests (AC: #1, #2, #3)
  - [ ] Pest: test categories endpoint, products by category, no auth required
  - [ ] Vitest: test HomePage and CategoryPage components
