# Story 2.2: Create Product Listing

Status: ready-for-dev

## Story

As a seller,
I want to add a new component with photo, name, description, specs, price and stock,
so that buyers can discover and purchase my products.

## Acceptance Criteria

1. **Given** a seller clicks "Add product" from their dashboard **When** the creation form loads **Then** they see fields for: photo upload, name, description, technical specs, price, stock quantity, and category selection (CPU, GPU, RAM, Stockage, CM, Alimentation, Boitier, Peripheriques)

2. **Given** a seller fills in all required fields and submits **When** the form is valid **Then** the product is created with status "active", the image is stored via scalable storage, and the seller is redirected to their dashboard with a success message

3. **Given** a seller submits an incomplete form (missing required fields) **When** the form is submitted **Then** validation errors are displayed for each missing field

## Tasks / Subtasks

- [ ] Task 1: Backend — Product model & migration (AC: #1, #2)
  - [ ] Create Product model with fields: name, description, specs (JSON), price, stock_quantity, category (enum), is_active, photo_path, seller_id (FK users)
  - [ ] Create migration for products table
  - [ ] Define category enum: cpu, gpu, ram, stockage, cm, alimentation, boitier, peripheriques
  - [ ] Add restock_date nullable field (for out-of-stock indication)
- [ ] Task 2: Backend — Create endpoint (AC: #2, #3)
  - [ ] Create SellerProductController@store (POST /api/seller/products)
  - [ ] Create StoreProductRequest Form Request (all fields required, photo max 2MB, price > 0, stock >= 0, category in enum)
  - [ ] Handle photo upload to storage (local disk for MVP, switchable to S3)
  - [ ] Associate product with authenticated seller
  - [ ] Return ProductResource
- [ ] Task 3: Frontend — Creation form (AC: #1, #2, #3)
  - [ ] Create ProductFormPage.vue (reusable for create and edit)
  - [ ] Add route /seller/products/create
  - [ ] Form fields: photo upload preview, name, description, specs (key/value pairs), price, stock, category dropdown
  - [ ] Client-side validation
  - [ ] Submit via multipart/form-data, redirect to dashboard on success
  - [ ] Display server validation errors
- [ ] Task 4: Tests (AC: #1, #2, #3)
  - [ ] Pest: test create product success, validation errors, photo upload
  - [ ] Vitest: test ProductFormPage component
