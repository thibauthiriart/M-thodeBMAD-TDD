# Story 2.5: Delete Product

Status: ready-for-dev

## Story

As a seller,
I want to permanently delete one of my products,
so that I can remove listings I no longer want.

## Acceptance Criteria

1. **Given** a seller clicks "Delete" on one of their products **When** a confirmation dialog appears and they confirm **Then** the product is permanently removed from the system

2. **Given** a seller clicks "Delete" and cancels the confirmation **When** the dialog is dismissed **Then** the product remains unchanged

## Tasks / Subtasks

- [ ] Task 1: Backend — Delete endpoint (AC: #1)
  - [ ] Create SellerProductController@destroy (DELETE /api/seller/products/{id})
  - [ ] Scope to authenticated seller's products
  - [ ] Delete associated photo from storage
  - [ ] Return 204 No Content
- [ ] Task 2: Frontend — Delete with confirmation (AC: #1, #2)
  - [ ] Add delete button on each product card in SellerDashboardPage
  - [ ] Show confirmation dialog before delete
  - [ ] Call API on confirm, remove product from store
  - [ ] Do nothing on cancel
- [ ] Task 3: Tests (AC: #1, #2)
  - [ ] Pest: test delete success, ownership check, product no longer in DB
  - [ ] Vitest: test delete confirmation dialog
